# ericamenin.com

Static portfolio site, generated by `build.py` and published by Netlify from the default branch (see `netlify.toml`). The generated HTML is committed; Netlify only runs `verify.py` before publishing.

## Preview

From this directory:

```sh
python3 build.py
python3 verify.py
python3 serve.py 8437
```

Open http://127.0.0.1:8437/. Python 3 is the only build/server dependency. The preview server binds to this computer only. `LAUNCH = True` in `build.py` is the published state; set it to `False` and rebuild to mark every page `noindex, nofollow` (the 404 page always is). `robots.txt` (AI crawlers explicitly allowed) and `sitemap.xml` are always generated in their launch form, matching the live site; bump `UPDATED` in `build.py` when content changes.

## Edit

- `content/site.json`: approved homepage copy, projects, writing, questions, terminal responses, and metadata.
- `build.py`: shared page, navigation, project, question, terminal, and footer templates. Generates static HTML; browser JavaScript is only used for interactions.
- `css/tokens.css`: web fonts, palette, semantic and spacing tokens. Loaded on every page.
- `css/next.css`: typography, layouts, responsive and motion styles. Loaded on every page, last.
- `css/case-study.css`: the pruned Webflow layout the preserved case-study bodies and the AI essay still need. Loaded only on those three pages, between the other two.
- `js/next.js`: navigation, questions, terminal and focus management.
- `js/motion.js`: contextual cursor, card tilt, email copy, gentle arrival motion.
- `js/gallery.js`: the Soniq carousel and native image dialog.
- `js/systems.js`, `content/systems.json`: the homepage experiment ("Break the system" and "Rebuild with" Carbon / Material / shadcn). `build.py` turns the JSON into `css/systems.css`; `verify.py` checks every system defines every role token.
- `source/`: retrieved published HTML and the approved handoff. These are preservation/reference files, not routes linked by the site. Do not rewrite the locked case studies here.
- `content/image-sizes.json`: intrinsic dimensions of preserved case-study images.
- `images/`: one folder per page (`design-system-back-in-sync/`, `soniq-design-system/`, `maturing-a-design-system/`), plus `site/` (favicon, touch icon, share image, portrait) and `icons/`. Numbered files follow their order in the case study; `-500`/`-800`/`-1080`/`-1600` are responsive sizes.

## AI and search

- `llms.txt`: plain-language summary for AI tools. Hand-written, so update it when the copy changes.
- JSON-LD on every page, generated from `content/site.json`: Person, WebSite and ProfilePage, an FAQPage that mirrors visible copy, the Substack posts, and one entry per case study and the AI page.
- Canonical URLs, Open Graph and `summary_large_image` Twitter cards, Apple touch icon.

The original case-study layout CSS and AI essay interaction are retained. `verify.py` compares every case-study body word (including captions, metrics, tables, and disclosures) with the retrieved source, compares the complete AI essay/rules, checks approved question/project/writing/about text, and validates internal destinations. Semantic heading levels, image dimensions, shared navigation, and presentation change; locked wording does not.

## Interaction and accessibility

Question rows use real buttons, independent expanded states, and controlled regions. Opening one question closes the others; the first starts open. The terminal supports typed/clicked commands, arrow keys, Enter, Escape, a command list, and focus restoration. `/` and Command/Ctrl+K open it. Native dialogs contain keyboard focus.

The original View/Read/Copy cursor vocabulary, staggered work composition, image hover/tilt, link highlighting, drawn crossout, and story/rules switch are retained or adapted. Reduced motion disables movement and the custom cursor; coarse pointers retain ordinary touch interactions. Content never waits behind an entrance animation.

Fonts load from Google Fonts; writing thumbnails retain their original Substack asset URLs. Other images are copied locally. No AI calls, shell execution, or live-server commands occur in the terminal.
