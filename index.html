What I’m exploring

A few thoughts I keep coming back to as I read, experiment, and work with design systems and AI. Here’s where I stand so far.

Subject to change… things move SO fast.

Tokens give values. Component properties give options. Neither explains when to use something or why an exception exists. That lives in documentation and component contracts: expected behavior, allowed combinations, accessibility requirements. The more explicit those are, the better the agent gets. Then the real question is whether it actually applies them.

Less than you’d think. One big AGENTS.md is tempting, but agents struggle with vague prose and files that never end. What seems to work better: a short file that points to where everything else lives, so the agent doesn’t read the whole system every run, and rules that grow each time the agent gets something wrong. For the rules that really matter, lint rules. Agents can’t skip those.

Teams are getting smaller, and “make the design system AI-ready” is one more big task on an already full list. I’d start small: a quick health check, then one problem that keeps coming back. An undocumented decision, a misleading example, a component people struggle with. One fix. One check. Then the next.

Don’t make your design system AI-ready yet ↗

Some teams already let agents maintain parts of their design system. Once a system is in good shape (audited, gaps fixed, agents know where to look), it can start taking care of itself. A component changes, an agent spots what no longer matches, fixes it, and opens a pull request. Audits and health checks could run the same way.

Agents do the work. We define what’s “right,” and test for it. That’s the idea behind an agentic design system, and what I’m exploring now.

A little about me

I’ve been in design for 15+ years and somewhere along the way became the person who gets excited about taking messy, complex things and making them work.

For a long time, that’s meant design systems, where I found my passion.

Now that AI is in the picture, there’s a whole new set of questions to work through. I’m exploring them here and writing about the wins, the awkward moments, and the “well, that didn’t work” parts at Design Systems Unfiltered.
